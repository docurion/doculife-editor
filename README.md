# DocuLife editor — source code

Zdrojový kód editoru dokumentů služby DocuLife (Docurion s.r.o.). Editor je sestavený z otevřeného
zdrojového kódu Collabora Online pod licencí Mozilla Public License 2.0 (MPL-2.0).

Každé vydání (release) obsahuje:
- archiv přesného zdrojového commitu, ze kterého je editor sestavený,
- úpravy Docurion s.r.o. ve formě patchů (MPL-2.0), použijí se příkazem `git apply` v pořadí podle názvu,
- `MANIFEST.txt` (obsah commitu) a `SHA256SUMS` (kontrolní součty souborů vydání).

The source code of the document editor of the DocuLife service (Docurion s.r.o.), built from the open
source code of Collabora Online under the Mozilla Public License 2.0. Every release holds the archive of the
exact upstream commit, our modifications as patches (MPL-2.0, applied with `git apply` in name order), the
commit's file list and the checksums of the release.
